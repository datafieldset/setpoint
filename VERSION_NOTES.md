# Setpoint v6.0

## Meter dot made more visible

Bigger dot (8px → 13px), thicker track (4px → 6px), a stronger gradient, and a subtle color-matched glow around the dot itself, red when leaning bearish, green when leaning bullish, nothing when it's near neutral. Small change, meant to make it easier to spot at a glance without turning it into something loud.

Verified with a real JSX parser before shipping, not just node --check, catching any syntax issue the way the actual build would.
